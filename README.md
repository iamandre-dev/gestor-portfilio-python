# Gestor de Portfólio Python

Projeto desenvolvido durante meus estudos iniciais de Python, como parte da Atividade Formativa da Semana 01.

## 🎯 Objetivo

Criar um programa capaz de receber um comando digitado pelo usuário e tomar uma decisão com base na informação recebida.

## ⌨️ Comandos disponíveis

* `ABOUT` — apresenta o Gestor de Portfólio.
* `QUIT` — encerra o programa.
* Outros comandos — apresentam uma mensagem de erro.

## 🧠 Conceitos praticados

* Variáveis
* `input()`
* `print()`
* `.upper()`
* `if / elif / else`
* Operadores de comparação
* Operadores lógicos

## 🚀 Sobre o projeto

Este projeto faz parte da minha evolução nos estudos de programação e tem como objetivo praticar os fundamentos da linguagem Python por meio de exercícios progressivos.
